# Changelog

## 1.0.0 (2026-09-15)

### Rilascio iniziale

- Dashboard: CPU, RAM, disco, batteria, uptime con grafici in tempo reale
- Processi: lista completa, ricerca, ordinamento, kill
- Controlli: volume, luminosità, blocca, sospendi, riavvia, spegni
- Screenshot remoto
- Clipboard sincronizzata PC ↔ iPhone
- Gestione finestre aperte
- Info rete e connettività
- Archiviazione e partizioni
- Audio Mixer (volume per applicazione)
- Terminale PowerShell remoto
- Keep Awake con timer
- Discord Canary + Vencord + Orion detection
- Apple Music telecomando via estensione browser
- Sistema aggiornamenti via GitHub Gist
- PWA con installazione su Home Screen
- Autenticazione PIN con scrypt
- Rate limiting e session management
- Safe Mode per blocco azioni pericolose
- Hardware profiling automatico (LOW/MEDIUM/HIGH)
- Ottimizzazione per hardware LOW con API native
- Zero telemetria, zero analytics, zero tracking
- Avvio automatico via Task Scheduler
